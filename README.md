# adweb-eindopdracht

A school assignment for making a finance-tracker in React.js, Typescript. It uses Next.js as a meta-framework.

## Run localy
1. Run `npm install`
2. Make a .env file and set your Firebase credentials. 
3. Copy the firebase rules from `firebase-rules.txt`
4. Run `npm run build`
5. Run `npm start`
6. Open https://localhost:3000
